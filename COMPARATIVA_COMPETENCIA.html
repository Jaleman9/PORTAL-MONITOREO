Benchmark de Analítica Web ONEST vs. Competencia

Respuesta técnica comparativa: Cómo mide el tiempo, comportamiento y gobernanza nuestra plataforma frente a PostHog, OpenReplay, Umami, Plausible y Matomo.

1 Matriz Comparativa de Herramientas

PostHog Analítica de producto y comportamiento Tiempo en pantalla, grabaciones de sesión y embudos por duración Docker / Kube / Cloud

ONEST Analytics Nuestra Plataforma Gobernanza corporativa, adopción de portales B2B y privacidad estricta (k ≥ 5) Duración de sesión (session_start/end), tiempo de carga real (NavigationTiming API), permanencia en SPAs e inactividad Docker Compose (ClickHouse + RabbitMQ + FastAPI)
2 ¿Cómo lo mido? (Métricas de Tiempo y Comportamiento)
⚡
Tiempo de Rendimiento y Carga Real
Core Web Vitals / Performance

Mide el tiempo exacto en milisegundos que tarda la página en responder y procesarse en el dispositivo del usuario real mediante la API nativa de los navegadores.

// SDK: PerformanceNavigationTiming
load_time_ms = performance.getEntriesByType('navigation')[0].duration;
⏱️
Duración de Sesión e Inactividad
Ciclo de Vida de Sesión

Controla sesiones activas en sessionStorage con caducidad tras 30 minutos de inactividad. Detecta el cierre o cambio de pestaña con visibilitychange y beforeunload.

Eventos: session_start | session_end | idle_timeout (30m)
🔄
Permanencia en SPAs (Single Page Apps)
Navegación Virtual React/Angular/Vue

Instrumenta automáticamente el History API (pushState, replaceState, popstate) para registrar transiciones de rutas sin recarga completa de página.

History.pushState() → Dispara page_view con page_path sanitizado
📊
Adopción y Cuentas Ociosas
KPIs Temporales de Negocio

Agregación en ClickHouse de DAU (Usuarios Diarios), MAU (Usuarios Mensuales), Ratio de Adopción (DAU/MAU) y alerta automática de cuentas con >30 días sin ingresar.

SELECT uniqExact(user_id_hash) FROM events GROUP BY event_date
3 ¿Con qué lo mido? (Arquitectura y Stack Tecnológico)
1. CLIENTE

SDK Web TypeScript (telemetry.js)

Script ultra-ligero (<12 KB), no intrusivo, sin cookies invasivas. Captura eventos automáticos y errores JS no controlados.

TypeScript / Vite
2. BORDE / INGESTA

Collector Service & Pseudonimización

API asíncrona de alta concurrencia. Valida contratos JSON Schema y aplica hash HMAC-SHA256 con salt secreto antes de encolar.

FastAPI / Python 3.11
3. MENSAJERÍA

RabbitMQ Event Buffer

Amortiguador de eventos asíncronos para tolerar picos masivos de telemetría sin pérdida de datos ni bloqueo de clientes.

RabbitMQ 3.13 (AMQP)
4. BASE DE DATOS

ClickHouse OLAP Columnar

Motor de almacenamiento analítico optimizado. Particionado mensual con TTL de retención de 90 días (minimización por ley).

ClickHouse MergeTree
5. GOBERNANZA & UI

Aggregation API & Dashboard Ejecutivo

Control de acceso basado en roles (RBAC) y filtro de privacidad k-anonymity (k ≥ 5) para prevenir reidentificación.

FastAPI + HTML5/CSS
4 Diferenciadores Clave frente al Mercado

Vs. PostHog / OpenReplay Seguridad PII

No graba la pantalla en video. Evita capturar datos bancarios, contraseñas o datos personales en formularios corporativos. Consume 95% menos ancho de banda.

Vs. Matomo / Google Analytics Rendimiento OLAP

No usa bases de datos relacionales lentas (MySQL). ClickHouse procesa millones de eventos analíticos en milisegundos con bajo costo computacional.

Vs. Umami / Plausible Gobernanza B2B

Diseñado para entornos corporativos: Soporte multi-portal, matriz RBAC (Ejecutivo vs Analista), k-anonymity (k ≥ 5) y observabilidad de errores frontend.
